# Pamarthi Vijay Kumar – Personal Portfolio 🚀

Welcome to the personal portfolio website of **Pamarthi Vijay Kumar**, an Engineering Student specializing in Artificial Intelligence & Data Science at Ramachandra College of Engineering.

## 🌟 Highlights & Features
- **Modern Futuristic Theme**: Crafted with light blue and mint green glassmorphism aesthetics, soft glow effects, and responsive cards.
- **Skills Showcase**: Featuring Programming Languages (Python, Java, C), Web Development (HTML, CSS, JavaScript), and Professional Skills.
- **Digital Creative Toolkit**: Genuine development, design, and AI productivity stack.
- **Achievements & Certifications**:
  - Major Hackathon & Startup awards (OptiForge Third Prize, MandiMitra 3rd Prize).
  - Participation Certificates from IEEE, RTIH, Prakalp, TechHive, etc.
  - Industry Online Certifications from **Infosys Springboard**, **Microsoft**, **AWS**, **UniAthena & Cambridge IQ**, **Board Infinity**, and **Udemy**.
  - Built-in full-screen interactive certificate lightbox.
- **Direct Connect**: Instant 1-click WhatsApp chat integration and direct Email option.

## 🛠️ Built With
- **React 18** with **TypeScript**
- **Vite** for fast modern frontend tooling
- **Tailwind CSS** for responsive styling & design tokens
- **Framer Motion** & **Lucide React** for smooth interactions and icons
- Standalone single-page fallback in `index.html`

## 💻 Local Setup & Development
1. Clone the repository:
   ```bash
   git clone https://github.com/parmarthivijaykumar-max/portfolio.git
   cd portfolio
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
